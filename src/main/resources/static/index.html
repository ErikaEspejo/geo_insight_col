GUÍA DE USO

Ayuda

GeoInsight presenta información geocientífica descriptiva. Sus resultados no representan evaluaciones de riesgo, amenaza o seguridad.

Explorar mapa

Activa una o varias capas y haz clic sobre una entidad para consultar sus atributos y procedencia. Las capas comienzan desactivadas.

Buscar y filtrar

Selecciona una capa, atributo y valor. Los valores del mismo atributo se combinan con O; atributos diferentes se combinan con Y. Selecciona una fila para acercarte al registro.

Consulta por coordenada

Ingresa longitud y latitud. Cuando esta herramienta está abierta también puedes hacer clic directamente en el mapa para consultar el contexto del punto.

Análisis de zona

Define un centro y un radio en metros, manualmente o con “Elegir punto en el mapa”. El sistema muestra conteos y distribuciones descriptivas dentro de la zona.

Comparación de zonas

Define las zonas A y B y un radio común. Puedes escribir las coordenadas o elegir cada centro en el mapa. Los resultados equivalentes se muestran lado a lado.

Administración

Permite gestionar únicamente entidades propias de GeoInsight; los registros del SGC son de solo lectura.
